# ⚜️ NOIR ERP — Gestão de Moda Masculina & PDV em PHP

Este é um sistema completo de gerenciamento comercial e Frente de Caixa (PDV) desenvolvido em **PHP estruturado** com foco no mercado de moda masculina minimalista de luxo, trazendo regras de negócio aplicadas ao varejo.

## 🔗 Link para Teste ao Vivo
👉 [Clique aqui para acessar o sistema publicado no FunilPro](https://funilpro.com.br)

## 🚀 Funcionalidades Principais
* **Design System Premium (Dark Mode):** Interface imersiva construída sob uma paleta de cores escuras profundas (`#121212`) e detalhes em dourado/âmbar, focando em alta fidelidade estética de marcas de grife.
* **Controle de Estoque Inteligente:** Listagem de vestuário e produtos gerenciada diretamente no servidor PHP, renderizando dados de SKU, preços e quantidades em tempo real através de loopings estruturados.
* **Sinalização Crítica de Usabilidade:** Alertas visuais automatizados na cor vermelha para produtos que atingem níveis críticos de estoque mínimo (abaixo de 5 unidades), otimizando a reposição do lojista.
* **Navegação Interativa Instantânea:** Painel lateral configurado via JavaScript para troca de janelas em tempo real (PDV, Estoque, Financeiro) com um clique, garantindo fluidez e eliminando recarregamentos lentos de página.
* **Checkout de Frente de Caixa (PDV):** Campo de busca rápida estruturado para receber entradas de SKU ou códigos de barras, simulando o fluxo ágil de automação de balcão de atendimento comercial.

## 🛠️ Tecnologias Utilizadas
* **Back-End:** PHP 8.x (Estruturação de dados, segurança de sessão e controle de rotas de login)
* **Front-End:** HTML5, CSS3 integrado e JavaScript Puro (Gerenciamento de janelas e ações dinâmicas de interface)
* **Framework Visual:** Bootstrap 5.3 (Responsividade mobile e padronização geométrica de componentes)
